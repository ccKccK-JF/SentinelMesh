# 原 monitor_system 参考审计

## 可复用的思路

- Worker/Manager 的节点与控制面分离。
- CPU、内存、磁盘、网络和软中断的指标覆盖范围。
- Protobuf 作为跨语言契约。
- 将 eBPF 用于内核网络路径观测。

## 不直接继承的实现

1. **为 CPU 计数器加载内核模块**：`/proc/stat` 和 `/proc/softirqs` 已提供对应数据，内核模块增加部署风险且没有必要收益。
2. **每批次创建 Unary RPC**：改为长生命周期双向流，并显式处理确认、重连和批次序列。
3. **高频指标直接写 MySQL**：改为最新状态内存存储和 Prometheus 时序存储。
4. **拼接 SQL**：如后续引入关系型数据库，必须使用参数化查询和连接池。
5. **固定权重评分**：保留为基线，后续增加硬门槛、平滑、滞回和冷却，并通过故障注入验证。
6. **配置写死在源码**：监听地址、阈值和存储配置统一从参数或配置文件注入。
7. **文档与代码状态不一致**：本项目使用完成度表和里程碑，未实现项明确标记。

## 版权与独立实现

新项目只参考系统边界和需求，不复制原项目实现代码。协议、控制面、采集器和测试均重新设计和实现。
